## 1. 环境准备

1. **从官网安装 OBS**：obsproject.com 下载 Windows 安装包（推荐官网版而非 Steam 版：
   - 版本更新最及时，不滞后
   - 不需要 Steam 客户端常驻后台，少一个进程
   - 更新时机完全可控）
2. **关闭自动更新**（直播中 OBS 突然自动更新重启是常见事故源）：
   `设置 → 常规 → 自动更新 → 选择「关闭」`
3. **确认编码器可用**：`设置 → 输出 → 流 → 编码器` 中能看到 `NVIDIA NVENC H.264` 即为正常。
   4070S 带双 NVENC 编码器，推流 + 录制同时开互不影响。

## 2. B站开播准备

1. 打开 [直播中心](https://live.bilibili.com) → 直播管理 → 我的直播间 → **开播设置**
2. 获取两样东西：
   - **推流地址**（如 `rtmp://live-push.bilivideo.com/live-stream/`）
   - **串流密钥**（一长串随机字符，每次开播前可重置，密钥泄露可作废重领）
3. 新版本 OBS 的推流服务下拉框里可直接选 **Bilibili Live**（2019 年版起内置，无需手填地址）

## 3. 推流参数配置

### 输出（设置 → 输出）

| 设置项 | 值 | 说明 |
|---|---|---|
| 输出模式 | 高级 | 推流/录制分开控制 |
| 编码器 | NVIDIA NVENC H.264 | 硬件编码，占用核心 |
| 码率控制 | CBR | 恒定码率，直播标准做法 |
| 码率 | 8000 Kbps | B站非签约主播推荐上限附近 |
| 关键帧间隔 | 2 秒 | **B站硬性要求，必须为 2** |
| 预设 | P6: Slower | 画质档，4070S 无压力 |
| 心理视觉调优 | 开启 | NVENC 画质关键开关 |
| 最大 B 帧 | 2 | 默认即可 |

> 编码器选 H.264 而非 HEVC/AV1 的理由：B站观众端兼容性最好，省去转码兼容问题的折腾。AV1 画质更好但受众支持度仍有限。

### 视频（设置 → 视频）

| 设置项 | 值 |
|---|---|
| 基础（画布）分辨率 | 1920 × 1080 |
| 输出（缩放）分辨率 | 1920 × 1080 |
| 常用 FPS | 60 |

### 音频（设置 → 音频）

| 设置项 | 值 |
|---|---|
| 采样率 | 48 kHz |
| 输出音频码率 | AAC 192 Kbps（立体声；纯人声可降 128） |
| 桌面音频 | 默认设备（含游戏声音）；**只推游戏声的配置见下方「音频路由」** |
| 麦克风/辅助音频 | 你的麦克风 |

> 直播码率 8000 Kbps 需要上行约 10 Mbps，普通家庭宽带（100M 上行通常够用）一般无压力。测速：`speedtest.cn` 看上行。

### 音频路由：只推游戏声音（不含语音软件/系统声）

不想让语音软件里的队友声、系统通知等进直播，只推游戏声 + 麦克风：

1. **先启动游戏**（应用捕获需要进程在运行才能选到）
2. OBS 源面板 → `+` → **应用音频捕获**
3. 属性里勾选「显示当前运行的应用」→ 下拉选游戏进程（如 game.exe）→ 确定
4. 音频混音器里把**桌面音频**音量拉到底（或点喇叭静音）——只影响 OBS 采集，**不影响你自己听到的声音**
5. 验证：混音器里桌面音频条不动、游戏条随游戏声音跳动、麦克风正常

注意：
- 部分游戏（独占音频模式/个别反作弊）不暴露进程音频，选不到或无声时才需要虚拟声卡（Voicemeeter）方案
- 游戏带启动器时音频可能在启动器进程，换选进程试到混音器里有跳动即正确
- 想恢复全部系统声音：把桌面音频音量拉回来即可

## 4. 低占用实践

1. **游戏捕获（Game Capture）** 而非显示器捕获：
   - 对游戏性能影响最小，FPS 掉帧可忽略
   - 支持全屏/无边框窗口；游戏需以管理员权限运行时，OBS 也要管理员权限运行
2. **关闭预览**：右键预览窗口 → 禁用预览。打游戏时不看 OBS 画面，省 GPU 解码负载
3. **场景精简**：场景里只放用得到的来源，避免叠加一堆无用滤镜
4. **Stats 面板监控**：`视图 → 统计`，开播后看：
   - 丢帧率应为 0（网络不稳的表现）
   - 编码器负载条不顶满
5. **游戏内限帧可选**：若不限帧且 GPU 满载，NVENC 仍有预留，但限帧到显示器刷新率更稳

## 5. 场景搭建

建议建 4 个场景，全部用**热键**切换：

| 场景 | 内容 | 切换热键 |
|---|---|---|
| 片头 | 封面图 / 网页动效 + 背景音乐 | Ctrl+1 |
| 游戏中 | 游戏捕获 + 摄像头 + 弹幕栏 | Ctrl+2 |
| 休息 | 摄像头 + 弹幕栏 + 休息画面 | Ctrl+3 |
| 结束 | 感谢画面 + 音乐 | Ctrl+4 |

热键配置：`设置 → 热键 → 找到各场景 → 设置快捷键`。

**摄像头推荐滤镜**（右键摄像头源 → 滤镜）：
- 噪声抑制（RNNoise，免费内置）
- 增益（音量合适即可）
- 若绿幕：色度键抠像 + 背景图片源

## 6. 趣味插件与玩法

### 6.1 blivechat —— B站弹幕/礼物上屏（推荐，主播标配）

仿 YouTube 风格的直播评论栏：弹幕、醒目留言(SC)、礼物、舰长/房管/主播名高亮、合并礼物、自动翻译、自定义表情、自定义 HTML 模板、插件系统。
（已通过 GitHub 官方仓库 `xfgryujk/blivechat` 核实，2026-08-12）

**方式 A：本地版（推荐，功能全）**
1. GitHub Releases 下载 Windows x64 版（或 B站商店搜「blivechat」）：`github.com/xfgryujk/blivechat/releases`
2. 双击 `blivechat.exe` 启动本地服务器
3. 浏览器打开 `http://localhost:12450`，输入**直播身份码**（开播后直播中心 → 开播设置里可获取），复制房间 URL
4. 用**样式生成器**生成样式，复制 CSS
5. OBS 添加「浏览器源」→ 填入房间 URL + 自定义 CSS 即可上屏

**方式 B：在线版（零安装，图省事）**
- 直接访问公共服务器：`blive.chat`（自动节点）/ `cn.blive.chat`（墙内节点）/ `cloudflare.blive.chat` / `vercel.blive.chat`
- 同一套流程：输身份码 → 复制房间 URL → OBS 浏览器源
- 注意：在线版禁用部分高级特性（插件、翻译等），且依赖作者维护

### 6.2 StreamFX —— 高级滤镜/转场（需付费，酌情）

功能：3D 变换、模糊、复杂遮罩、自定义着色器（Shader）、转场效果等，OBS 生态最强的滤镜全家桶。

**现状（2026-08 核实）**：原 GitHub 仓库 `Xaymar/StreamFX` 已私有化（404），官方公开仓库迁至 `Vhonowslend/StreamFX-Public`，仅公开源码、Release 无安装包。安装包需通过作者 Patreon 支持获取。旧版（OBS 27 时代）曾免费，新版对 OBS 28+ 收费。

**免费替代方案**（效果已覆盖日常需求）：
- 转场：OBS 内置转场 + **Stinger 视频转场**（自定义带 alpha 的过场视频，`设置 → 转场 → 添加 Stinger`）
- 模糊/遮罩：OBS 内置滤镜（裁剪、色度键、图片遮罩）足够日常
- 自定义效果：浏览器源里放 HTML/CSS/JS 动效，可玩性其实最高（见 6.3）

### 6.3 浏览器源玩法（免费，可玩性天花板）

OBS「+」→ 浏览器 → 输入 URL，即可把任意网页嵌进画面：

| 玩法 | 说明 |
|---|---|
| 弹幕栏 | blivechat（见 6.1） |
| 事件通知 | 关注/礼物弹出动画，用 blivechat 插件系统或自建网页 |
| 时钟/日期 | 任意网页时钟，半透明叠加角落 |
| 点歌/互动面板 | 本地起个小服务（如基于 blivechat 插件系统），网页展示点歌队列 |
| 直播间数据 | 粉丝牌、在线人数等面板 |

> 浏览器源会加载网页、占用少量内存和 GPU 合成资源。场景里别挂太多，一般 2~3 个够用。遇到网页不显示，先在浏览器源设置里点「刷新」。

### 6.4 其他内置能力（无需装任何东西）

- **虚拟摄像头**：OBS 输出作为摄像头喂给腾讯会议/Zoom（`工具 → 虚拟摄像头`）
- **obs-websocket**：OBS 28+ 自带（`工具 → WebSocket 服务器设置`），后续想用脚本自动切场景、开录、控制推流都靠它
- **多音轨录制**：录制时音轨分开（游戏声/麦克风/伴奏），后期剪辑灵活
- **Studio 模式**：预览画面调好后一键切出，观众不会看到你调东西的过程

### 6.5 动图贴纸（GIF / WebM）

1. `+` → **媒体源** → 选本地 `.gif` → 勾选「循环」→ 确定，拖到画面任意位置即可
2. **透明动图用 WebM 不用 GIF**：GIF 透明是 1-bit，边缘锯齿明显；要高质量透明动画（卡通形象、光效）用 WebM（VP9 带 alpha），媒体源同样支持
3. **性能**：GIF 是 CPU 解码，小尺寸贴纸无压力；大尺寸/长动画转 WebM 再上
4. **热键一键弹贴纸**：`设置 → 热键` → 找到该源 → 设「切换可见性」快捷键，直播中按键弹出/收起，无需切场景

## 7. 开播前检查清单

- [ ] OBS 自动更新已关闭
- [ ] 推流地址 + 串流密钥已填入，服务选 Bilibili Live
- [ ] 编码器 NVENC H.264、CBR 8000、关键帧 2s、P6: Slower、心理视觉调优开
- [ ] 游戏用游戏捕获，预览已禁用
- [ ] blivechat 已启动，浏览器源加载出弹幕
- [ ] Stats 面板开着（丢帧 0、编码负载正常）
- [ ] 试播 2 分钟：观众端确认画面、声音、弹幕、延迟正常

## 8. 常见问题排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 丢帧（网络红条） | 上行带宽不足 | 码率降到 6000；关掉占用带宽的后台下载/同步 |
| 画面模糊/糊 | 码率过低或缩放设置不对 | 确认输出分辨率 1080p；码率提到 8000；检查「缩放滤镜」选 Lanczos |
| 游戏捕获黑屏 | 权限或兼容问题 | OBS 以管理员运行；游戏先开捕获后开；试试窗口捕获 |
| 观众听不到声 | 音频路由错误 | 确认桌面音频选了正确的输出设备；B站侧确认推流声音未静音 |
| 延迟过大 | 网络链路问题 | 用 B站默认推流节点；别用代理；测 `bilibili` 上传延迟 |
| 弹幕源白屏 | 网页加载失败 | 浏览器源设置点「刷新」；确认本地服务（12450 端口）还活着 |
| OBS 更新后插件失效 | 插件不兼容新版本 | 升级前看插件是否支持新版本；重要插件可临时回滚 OBS 版本 |

*配置参数基于 RTX 4070 Super + 1080p60 游戏直播实测调优；显卡/分辨率/网络不同时按第 3 节规则等比调整。*
