## 快速使用（5 分钟上手）

### 界面一览

```
┌──────────────────┬──────────────────────────┬──────────────────┐
│   左侧：输入       │    中间：时间轴 + 陀螺图表   │   右侧：参数 + 输出  │
│                  │                          │                  │
│  · 视频信息       │  ┌─────────────────────┐ │  · 稳定参数        │
│  · 镜头配置       │  │  陀螺仪数据图表       │ │  · 平滑度          │
│  · 运动数据       │  │  浅色线 = 光流估计     │ │  · 水平锁定        │
│                  │  │  深色线 = 传感器数据    │ │  · 缩放模式        │
│                  │  │  竖线   = 同步点       │ │  · 导出设置        │
│                  │  └─────────────────────┘ │                  │
└──────────────────┴──────────────────────────┴──────────────────┘
```

### 第 1 步：加载视频

将视频文件拖入 Gyroflow 窗口，或点击左侧 **Open video file** 选择文件。

软件自动检测：相机型号、分辨率、帧率、编码格式、是否包含陀螺仪数据。

> ⚠️ **慢动作视频**：如果 120fps 拍摄但文件标记为 30fps，需要在 **Frame rate** 字段手动填入实际拍摄帧率（如 NTSC 制式为 `119.88`，PAL 制式为 `100`）。

### 第 2 步：镜头配置

- **免操作相机**（自带内置镜头配置）：GoPro Hero 6-13、Sony、DJI、Insta360 — 自动加载，直接下一步
- **其他相机**：在 **Lens profile** 下拉框中搜索你的相机型号，或点击 **Create new** 自行校准（见[镜头校准](#镜头校准)章节）

### 第 3 步：同步（最关键！）

> **免同步相机**：GoPro Hero 8+、DJI、Sony、Insta360、Blackmagic RAW — 可跳过此步，直接进入第 4 步。

1. 在时间轴上找一个**有明显运动**的位置
2. 右键 → **Auto sync here**（快捷键 `a`）
3. 重复 2-3 次，获得 2-3 个同步点
4. 播放视频验证稳定效果

**如何判断同步是否正确？**

- ✅ 播放该位置时画面稳定
- ✅ 图表中浅色线与深色线大致对齐
- ✅ 同步点颜色为绿色（仅作参考）
- ❌ 不同同步点的数值差异很大（如 10ms、-50ms、70ms）→ 删除异常点，重新同步

### 第 4 步：调整稳定参数

| 参数 | 建议值 | 说明 |
|---|---|---|
| **Smoothing algorithm** | Default | 不要改，99.5% 的情况用这个 |
| **Smoothness** | 0.5 | 越大越平滑，但裁剪也越多 |
| **Zooming** | Dynamic zooming | 动态裁剪，最大化保留画面 |
| **Zooming speed** | 2-5 秒 | 缩放过渡时间 |

### 第 5 步：导出

1. 按 `i` / `o` 键设定导出范围（可选）
2. 选择输出格式（H.264 通用，H.265 画质更好，ProRes 适合继续剪辑）
3. 点击蓝色 **Export** 按钮

## 主要功能介绍

### 核心原理

Gyroflow 的工作流程分为四个步骤：

```
相机传感器 (IMU)  ──▶  陀螺仪/加速度计数据
                                            │
                  ① 同步 (Synchronization)  │  将运动数据与视频帧对齐
                  ② 镜头去畸变              │  消除镜头光学畸变
                  ③ 运动平滑               │  对相机姿态做平滑处理
                  ④ 裁剪输出               │  去除边缘黑边
                                            │
相机镜头          ──▶  视频帧
```

> 📌 **成功的稳定 = 准确同步 + 准确镜头配置 + 正确的卷帘快门值**

---

### 三种平滑算法

Gyroflow 提供三种平滑算法，但**绝大多数场景只需要 Default**。

#### Default — 始终首选

Default 是 Gyroflow 的完整稳定算法，包含四元数平滑 + 自适应约束、水平锁定支持、分轴平滑（Pitch/Roll/Yaw 独立控制）、智能优化裁剪路径以尽量减少缩放。

> 📌 官方推荐：**99.5% 的场景都用 Default**。

#### Plain 3D — 基本不需要用

Plain 3D 是更简单、更原始的 3D 旋转平滑算法。它只做基础的三维旋转平滑，**不做裁剪路径优化**，因此稳定后的画面往往需要**更大的缩放**才能覆盖黑边。

| 对比维度 | Default | Plain 3D |
|---|---|---|
| 裁剪路径优化 | ✅ 智能优化，最小化裁剪 | ❌ 无优化，裁剪量大 |
| 水平锁定 | ✅ 支持 | ✅ 支持 |
| 分轴平滑 | ✅ 支持 | ❌ 不支持 |
| 推荐使用 | ✅ 永远用这个 | ❌ 没有理由主动选它 |

> ⚠️ 如果你发现画面被过度裁剪，检查是否误选了 Plain 3D，改回 Default。

#### Fixed Camera — 特殊场景

假设相机**位置固定不动**、只有旋转（类似三脚架上的云台旋转）。如果相机实际发生了平移运动，数学模型就会失效 → **画面全黑**。

> 🔧 **排查口诀**：画面黑 → 改回 Default；太放大 → 改回 Default。

| 算法 | 说明 | 使用场景 |
|---|---|---|
| **Default** | 完整稳定算法，自适应裁剪优化 | ✅ **默认使用，99.5% 场景** |
| **Plain 3D** | 纯 3D 旋转平滑，无裁剪优化 | ⚠️ 误选会导致**过度放大** |
| **Fixed Camera** | 假设相机位置固定不动 | ⚠️ 误选会导致**画面全黑** |

---

### Default 算法参数微调指南

**默认设置不等于"最好"**，它只是一个适合大多数场景的通用起点。选了 Default 算法后，还有大量参数可以微调来获得更好的结果。

#### 不同场景对默认值的反应

| 场景 | 默认 Smoothness=0.5 的表现 |
|---|---|
| 手持走路 | OK，但可能仍有颠簸 |
| FPV 穿越机 | 太强，画面可能过度"漂浮" |
| 车载/航拍 | OK，但地平线可能不够平 |
| 固定机位（三脚架但风吹） | 太弱，微抖动去不掉 |

#### 可调参数（按重要性排序）

**1. Smoothness（平滑度）— 最核心的旋钮**

| 值 | 效果 | 适合场景 |
|---|---|---|
| `0 ~ 0.3` | 轻度平滑，保留更多原始运动感 | FPV 穿越机、主观视角 |
| `0.5`（默认） | 中等平滑 | 通用 |
| `0.7 ~ 1.0` | 强平滑 | 手持行走、车载 |
| `> 1.0` | 极强平滑 | 需要"漂浮感"的航拍镜头 |

> ⚠️ 平滑度越高 → 需要更多裁剪 → 画面损失越大。这是核心权衡。

**2. Per-Axis Smoothness（分轴平滑）— 精细控制**

Default 算法下可以独立控制三个轴向的平滑程度：

| 轴 | 控制的是 | 降低平滑 | 提高平滑 |
|---|---|---|---|
| **Pitch** | 上下俯仰 | 保留抬头/低头的动作 | 消除走路上下晃动 |
| **Roll** | 左右倾斜 | 保留倾斜感 | 更接近水平锁定 |
| **Yaw** | 左右旋转 | 保留转身动作 | 消除左右摇摆 |

> 📌 **典型用法**：手持走路时 Yaw 晃动最明显，可以把 Yaw 平滑拉高，Pitch 保持适中，避免画面太"死"。

**3. Max Smoothness / Max Smoothness at High Velocity**

这两个参数是"安全帽"，防止平滑过度：

| 参数 | 作用 |
|---|---|
| **Max Smoothness** | 正常速度下的平滑上限，防止画面过于迟钝 |
| **Max Smoothness at High Velocity** | 快速运动时的平滑上限，防止高速旋转时画面失控 |

> 📌 如果你把 Smoothness 拉很高但画面在快速移动时感觉怪，调低这两个上限。

**4. Zooming（缩放控制）— 直接影响观感**

| 参数 | 默认 | 调整建议 |
|---|---|---|
| **Zooming Speed** | 2-5s | 值越小 → 缩放过渡越快越不自然；值越大 → 过渡越慢但裁剪停留时间长 |
| **Zooming Method** | Gaussian Filter | 替代选项 **Envelope Follower** 可能看起来更自然，尤其在用了关键帧时 |
| **Zooming Center Offset** | 居中 | 竖屏输出（9:16）时可关键帧控制跟踪主体 |

**5. Horizon Lock（水平锁定）**

- 开启后保持地平线水平，适合航拍和车载
- **Horizon Lock Roll** 细调滚转角
- 如果有 Gravity Vectors 可以勾选试试（不是总比不勾好，需实测对比）
- 可关键帧控制：只在需要水平的部分开启（如航拍直线飞行段），其他时间关闭以节省裁剪

**6. Lens Correction Strength（镜头校正强度）**

控制去畸变的程度。如果觉得画面边缘拉伸不自然，可以适当降低。

**7. Rolling Shutter Correction（卷帘快门）**

如果画面有"果冻效应"（快速左右摇摄时竖线变斜线），填入正确的 **Frame Readout Time**。改完之后必须**重新同步**。

**8. 关键帧 — 让参数随时间变化**

大部分参数都可以在不同时间设置不同值：

- 开场慢慢飞 → 高平滑、水平锁定开启
- 中间快速穿越 → 低平滑、水平锁定关闭
- 结尾停下来 → 中平滑

用法：右键任意滑块 → **Enable keyframing** → 在不同时间点改变数值。

#### 推荐调参顺序

```
第 1 轮：只调 Smoothness
  → 找到一个适合你素材的大致范围

第 2 轮：调整 Zooming Speed
  → 让裁剪的"呼吸感"尽量自然

第 3 轮：需要的话开启 Horizon Lock
  → 航拍/车载必开，其他场景按需

第 4 轮：如果某轴向有特定问题
  → 分轴调整 Pitch/Roll/Yaw

第 5 轮：精细控制
  → 关键帧 + Max Smoothness 微调
```

> 📌 一句话：**默认设置是好的起点，但最佳效果来自于根据具体素材做针对性微调。** 最关键的三个旋钮是 Smoothness、Zooming Speed、Horizon Lock。

### 三种缩放模式

| 模式 | 行为 | 优点 | 缺点 |
|---|---|---|---|
| **Dynamic Zooming** | 缩放量动态变化，不同段落裁剪量不同 | ✅ 最大化利用画面 | 有轻微缩放"呼吸感" |
| **Static Zoom** | 整段统一使用最大裁剪量 | 无缩放变化 | ❌ 裁剪量大 |
| **No Zooming** | 只稳定不裁剪 | 保留完整画面 | ❌ 边缘出现黑边 |

**Zooming Speed**：控制缩放过渡时间，典型值 2-5 秒。

---

### 水平锁定

开启 **Horizon Lock** 后，Gyroflow 会保持地平线始终水平，同时稳定其他轴向。

- ✅ 适合：航拍、车拍等需要保持水平的场景
- ⚠️ 代价：需要更大裁剪量
- 🔧 可调整：**Horizon lock roll** 滑杆微调滚转角，也可[关键帧](#关键帧)控制不同时间的锁定程度

部分相机内置重力向量（Gravity Vectors），勾选可提升水平锁定精度（需实测对比效果）。

---

### 卷帘快门校正

大多数消费级相机使用卷帘快门传感器（逐行扫描）。快速左右摇摄时直线会变弯，Gyroflow 通过 **Frame Readout Time**（传感器完整读取一帧的时间，单位 ms）来校正。

| 相机类型 | 是否需要手动设置 |
|---|---|
| GoPro、Sony、DJI、Insta360、Blackmagic RAW | ❌ 自动处理 |
| 其他相机（RED、Canon、RunCam、手机等） | ✅ 需手动填写 |

> ⚠️ 改变此值后必须**重新同步**所有同步点。

### 镜头校准

如果找不到你的相机镜头配置，需要自行校准：

#### 录制校准视频

1. 打开 Gyroflow → **Lens profile** → **Create new** → **Open calibration target**
2. 将棋盘格图案在**平面显示器**上全屏显示（越大越好，曲面屏不可用）
3. 录制约 60 秒，反复覆盖以下 5 种姿态（每种多次出现）：

| # | 拍摄姿态 | 说明 |
|---|---|---|
| 1 | 棋盘格充满整个画面 | Chessboard filling whole frame — 靠近屏幕，让棋盘格占满 |
| 2 | 从远处拍摄 | Chessboard seen from distance — 远离屏幕，棋盘格在画面中较小 |
| 3 | 从倾斜角度拍摄 | Chessboard seen at an angle — 侧向拍摄，让棋盘格有透视变形 |
| 4 | 画面四边分别对齐棋盘格边缘 | Each edge of video frame aligned with edge of chessboard — 棋盘格边对准画面边 |
| 5 | 棋盘格角对齐画面角 | Corner of chessboard aligned with corner of video — 让棋盘格角处于画面角 |

4. 最后加入**快速左右摇摄**（用于估算卷帘快门）

#### 分析校准

1. 在 Gyroflow 中加载校准视频
2. 自动校准或手动添加校准点（跳过最后的快速摇摄部分）
3. **Reprojection error** 应 < 5 像素（优秀校准 < 1 像素）
4. 填写预设信息并导出 `.json` 镜头配置文件

### 同步点

同步点是 Gyroflow 最重要的概念。每个同步点有一个时间偏移值（ms），表示运动数据需要偏移多少才能与视频对齐。

#### 同步点数值的规律

| ✅ 好的同步点 | ❌ 有问题的同步点 |
|---|---|
| 49.5, 50, 50.5, 51 | 0.5, -100, -150, 20 |
| -1400, -1405, -1407, -1408 | -120, -130, 25, -150 |
| 20.4, 20.4, 20.2, 20.0 | 1500, 120, 45, 5 |

> 📌 规律：所有同步点值应接近或呈线性渐变，不允许出现矛盾的大幅跳变。

#### 同步点颜色

- 🟢 **绿色**：与该段的线性拟合一致，通常正确
- 🔴 **红色**：偏移值偏离整体趋势，可能异常
- ⚠️ RunCam 相机请忽略颜色

#### 外部陀螺仪源同步

如果使用外部陀螺仪记录器（如飞控 Blackbox、ESP-gyrologger、手机 App 等）：

- **Rough gyro offset**：你对偏移量的初步估计（如先开记录器等 30 秒再开相机，则填 `30s`）
- **Sync search size**：在估计值附近搜索的范围
- 扫描范围 = `rough_offset ± search_size`

### 关键帧

大部分参数都可以在不同时间点设置不同值，实现精细化控制。

#### 如何使用

1. 右键滑块 → **Enable keyframing**
2. 在需要改变值的时间点调整滑块 → 自动创建关键帧点
3. 右键关键帧点 → 可切换缓入缓出（Easing）或线性过渡

#### 支持关键帧的参数

平滑度、FOV、缩放速度、缩放中心偏移、水平锁定量/滚转校正、镜头校正强度、最大平滑度、高速运动下的最大平滑度、Pitch/Roll/Yaw 轴向平滑度、视频旋转、背景边距/羽化、视频速度

> ⚠️ 关键帧控制缩放速度时，建议将缩放算法切换为 **Envelope Follower**（Gaussian Filter 算法有已知 bug，可能导致黑边）。

### 导出编码

| 编码 | 兼容性 | 画质效率 | 推荐场景 |
|---|---|---|---|
| **H.264/AVC** | ⭐⭐⭐⭐⭐ | 一般，8-bit | 通用分享、社交媒体、Web |
| **H.265/HEVC** | ⭐⭐⭐ | ⭐⭐ 更好，支持 10-bit | 高质量存档、存储有限时 |
| **ProRes** | ⭐⭐⭐ | ⭐⭐⭐ 专业级 | 后期剪辑中间片 |
| **DNxHD** | ⭐⭐ | ⭐⭐⭐ 专业级 | 与 ProRes 类似，无硬件加速 |
| **CineForm** | ⭐⭐ | ⭐⭐⭐ 专业级 | 同上 |
| **EXR 序列** | ⭐ | ⭐⭐⭐ 32-bit 浮点无损 | VFX、合成 |
| **PNG 序列** | ⭐⭐ | ⭐⭐ 8/16-bit 无损 | 帧序列交付 |

#### GPU 加速

- 强烈建议开启 GPU 编码，速度远超 CPU
- H.264/H.265 所有主流显卡均支持，ProRes 仅 Apple Silicon 加速
- 追求极限画质可关闭 GPU 编码使用 CPU（慢很多，但质量略好）

### 视频编辑器插件

不想在 Gyroflow 内渲染？可以在剪辑软件中直接稳定原始素材。

#### 支持平台

| 编辑器 | 插件类型 |
|---|---|

#### 工作流

2. 按 `Ctrl+S` 导出 `.gyroflow` 项目文件（包含所有参数 + 陀螺仪数据）

## 常见问题排查

> ⚠️ **90% 的稳定失败都源于这三个问题：同步不准、镜头配置不对、卷帘快门值错误。** 在调整任何参数之前，请先确认这三者都是正确的。参数微调是在三者都对的前提下才有效的优化。

| 问题 | 可能原因 | 解决方案 |
|---|---|---|
| 画面变黑 | 误选了 **Fixed Camera** 算法 | 改回 **Default** |
| 画面过度放大 | 误选了 **Plain 3D** 算法 | 改回 **Default** |
| 稳定效果不好 | 同步不准 | 删除所有同步点，在运动明显处重新 Auto Sync |
| 稳定效果不好 | 镜头配置不准 | 重新校准镜头或换匹配的配置 |
| 稳定效果不好 | 卷帘快门值不对 | 修改 Frame Readout Time 后重新同步 |
| 画面扭曲/摇晃 | 卷帘快门未校正 | 填入正确的 Frame Readout Time |
| 渲染太慢 | 未开启 GPU 编码 | 确保勾选 GPU encoding |
| HEVC 导出失败 | 显卡/系统太旧 | 改用 H.264（2012 年前的硬件可能不支持） |
