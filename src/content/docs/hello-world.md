## 为什么写技术文档

技术文档是知识沉淀最好的方式。写下来不仅帮助自己理清思路，也能在未来回顾时快速找回当时的上下文。

## 前端开发的一些思考

现代前端开发已经不再是简单的 HTML + CSS + JS。从构建工具到框架选型，从状态管理到性能优化，每个环节都值得深入探讨。

### 关于框架

React、Vue、Svelte、Solid……每个框架都有其设计哲学。选择框架不在于追新，而在于理解它解决什么问题，以及你的项目真正需要什么。

### 关于 TypeScript

类型系统不是束缚，而是工具。好的类型设计能让代码自文档化，让重构更有信心。
