# 路线图

更新日期：2026-09-29

路线图只记录仍影响当前实现的阶段和后续方向。更细的提交历史以 Git 为准。

## 当前状态

- Astro 静态站已部署到 Cloudflare Pages。
- zh/en 路由、主题、SEO、sitemap 和 Pagefind 已上线。
- 关于页、技术文档、唱片架、跨页播放器和摄影画廊均可用。
- 媒体通过本地 CLI 转码并上传 R2。
- 首页已重构为跟随明暗主题的大标题与人物前景构图。
- ClientRouter 保留用于播放器持久化，根页面转场已经关闭。
- 首页已改为 Custom Element 生命周期，解决返回首页后的 DOM/事件状态叠加。
- 全部站内页已统一为展览画册式视觉系统，并完成自托管中英文字体与纯黑暗色主题。

## 已完成阶段

### 基础与内容系统

- Astro 静态骨架、Design Tokens、双语 UI 和自定义 404。
- Content Collections 文档列表与详情。
- Shiki 双主题、Markdown 表格和正文排版增强。
- Pagefind 内嵌搜索、日期排序和键盘操作。

### 音乐与摄影

- R2 自定义域名和跨域媒体访问。
- 专辑架、曲目播放、持久化播放器、黑胶与唱臂动效。
- 照片墙/时间线、札记搜索、Lightbox 和图片错误状态。
- 音乐与摄影 JSON 单一数据源。

### 响应式与主题

- 桌面侧栏和 640px 手机抽屉。
- `dvh`、safe-area 和横屏播放器可达性。
- 浅色、深色、自动主题与 Shiki 同步。
- canonical、Open Graph 基础信息和 sitemap。

### 内容工具

- `photos`：RAW/JPG 处理、缩略图、EXIF 和数据写回。
- `album`：ID3、封面、LRC、数据写回和上传。
- `ncm`：本地转换。
- `review`：音乐/摄影札记编辑。
- R2 S3 multipart、immutable 缓存和自动校验。

### 首页与导航生命周期

- 首页以 `doebkblcya` 大标题和人物画作为核心构图，背景跟随明暗主题。
- 单次滚轮/触摸/键盘操作完成展开或收回。
- 展开态在桌面和手机上分离标题、人物与导航。
- Astro 旧组件名 `ViewTransitions` 更新为 `ClientRouter`。
- 移除全局左右滑页动画，避免页面快照与首页动效冲突。
- 首页事件和 Motion 状态由 `<home-hero>` 挂载/销毁。

### 整体视觉重构

- 左侧竖向导航改为排版式目录，移动端继续使用抽屉。
- 关于、文档、音乐、摄影、详情和 404 统一使用 12 列逻辑、结构线、直角控件与编辑型标题。
- 全站浅色采用纸白画布，深色采用纯黑。
- Newsreader、Hanken Grotesk、JetBrains Mono、Noto Serif SC 和 Noto Sans SC 通过可变 WOFF2 自托管。
- 播放器完成桌面与手机布局重排，放大收纳态唱片，消除唱臂与文案遮挡，并移除多余关闭按钮。
- 首页完成桌面人物顶部边界和中等视口比例修正；手机播放器工具栏改为两行稳定栅格。
- 开发环境跳过 Pagefind 初始化，消除不存在构建索引时的脚本 404。

## 下一步

按优先级：

1. 将 Sidebar 与 LanguageSettings 从全局 `window.__vt_*` 迁移到组件生命周期。
2. 将文档列表、音乐页、摄影页的 inline handler 分批迁移为 Custom Element。
3. 为首页往返、history、主题、语言和播放器持久化建立仓库内浏览器回归测试。
4. 清理 `astro check` 中 define:vars 与 deprecated event 相关提示。
5. 持续补充技术文章、专辑和摄影内容。
6. 评估 LRC 歌词展示；只有在不扩大播放器复杂度时实现。

## 维护原则

- 优先修正生命周期和可访问性，再增加装饰效果。
- 新功能不能扩大 ClientRouter 全局状态。
- 首页保持无解释文本的视觉入口。
- 内容数量从数据文件获取，不手工同步到多个文档。
- 每个阶段完成后同步 `README.md`、`AGENT.md` 和受影响的 `docs/` 文件。

## 不在计划内

- 登录、评论、点赞、统计后台
- 文档分类/归档页、独立搜索页
- RSS、标签云、热力图
- 正文自动翻译
- 全站方向滑页、纯装饰滚动视差和拖拽
- 播放器跨元素 morph
