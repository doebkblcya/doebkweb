# 路线图

更新日期：2026-10-01

## 本轮重构

- 音乐库改为专辑封面、静态资料和用户乐评，移除播放与跨页面状态。
- 唱片页新增默认“选集”：从有乐评的作品中随机选出最多三张，以封套抽出唱片和文字展开呈现；完整收藏继续在“唱片架”搜索、按专辑名/艺术家排序。
- 普通多页面导航 + 原生 VT，正文简短转场，保留现有首页动画。
- 摄影保留原网格排版和札记样式，使用原生大图弹窗、搜索、照片墙/时间线。
- 移除旧媒体 CLI；AI 文档与本地小工具负责图片准备、清单校验，Wrangler 负责上传。
- R2 已清空，摄影与专辑公开数据重置；原有专辑名和乐评保留为重新录入参考。

## 下一步

1. 用户确认页面构图和比例。
2. 用真实相机 RAW 验证内嵌 JPEG 提取；JPEG/PNG 处理和 R2 发布已用首批素材实际验证。
3. 继续录入专辑，查找复审资料、上传封面并补充用户乐评。

## 原则

保持静态站和清晰多页面结构，不引入播放器、专辑运行时 API 或集成媒体 CLI。上传与网页发布分开，AI 完成重复操作；用户负责专辑信息复审、乐评与远程清理。
