# 产品需求

更新日期：2026-10-01

## 定位与页面

个人介绍、技术文档、专辑乐评和摄影作品组成纯静态个人站。保留 zh/en 多页面路由及现有首页，不引入后端、账户、数据库或评论服务。

| 页面 | 路由 | 职责 |
|---|---|---|
| 首页 | `/[lang]/` | 大标题、人物和独立展开导航 |
| 关于 | `/[lang]/about/` | 自述与联系方式 |
| 文档 | `/[lang]/docs/` | 日期排序、全文搜索 |
| 文档详情 | `/[lang]/docs/[slug]/` | 正文、元信息、目录 |
| 唱片 | `/[lang]/music/` | 专辑封面、资料、乐评 |
| 摄影 | `/[lang]/photos/` | 照片墙、时间线、大图 |
| 404 | `/[lang]/404/` | 错误说明与首页入口 |

## 体验

- 保留首页大标题和人物构图，展开后导航可点击；无额外说明文字。手机与桌面布局、快速反向操作和 reduced-motion 行为保持。
- 内页采用细线、直角、编辑字体和留白。桌面固定侧栏，640px 以下移动抽屉；设置选择中英文及浅色/深色/系统主题。
- 侧栏底部“设置”入口与导航文字左对齐、同宽，上方保留一条细线，无图标和方框。
- 普通多页面导航配合原生 VT，正文约 90ms 淡出、280ms 淡入并上移 6px，侧栏稳定；不动画化模糊。首页不参与跨文档转场；不支持的浏览器正常切页。
- 文档、摄影与唱片工具栏的搜索框、排序/视图控件保持同一字号、内边距、图标与选中样式，移动端统一换行。
- 内页标题区域保持适度留白；标题分隔线与紧接的工具栏上边线合并，避免双线之间出现空白夹层。关于页和文档详情页使用同一套页头间距。
- 主题刷新与前进/后退保持；动效遵守 reduced-motion，键盘可用，无横向溢出。
- 全站不显示关闭按钮或叉号。设置、专辑和摄影弹窗通过点击背景或 Escape 关闭；移动端菜单通过遮罩、Escape 或再次点击菜单入口收起。
- 设置、专辑和摄影弹层背景统一使用 28px 高斯模糊和 65% 黑色遮罩，参数在全局 token 中集中维护。

## 专辑

- 移除在线播放、播放器、试听、播放列表、音频持久化和歌词处理。
- 详情底部显示“播放”和 Apple Music 专辑跳转链接，不展示资料来源；来源链接仅保留在数据中供维护核对。
- 两种形态：“选集”为默认视图，只纳入已写乐评的专辑；每次进入随机展示最多三张，避免与本标签页上一次顺序相同，阅读期间和历史返回时顺序固定。不足三张时全部展示。
- 选集完整展示封面、专辑名、艺术家、年份和用户乐评；唱片从封套侧边抽出、文字稍后展开，每次进入视线时重播，离开视线后复位，阅读时静止且不改变顺序。使用 CSS 和 IntersectionObserver，遵守 reduced-motion。手机上封面在上、文字在下。
- “唱片架”展示全部专辑，保留搜索与专辑名/艺术家 A–Z 排序、稳定的封面网格。两种形态都可点击封面打开居中的详情弹层：半透明高斯模糊背景，无关闭按钮，通过点击背景或 Escape 关闭。
- 用户给专辑名，AI 在录入时查资料并提交复审；乐评保持用户原文。
- 完整信息写入静态 JSON，封面上传 R2。网站构建/运行不查外部 API。
- 封面提供长边不超过 360px 的 WebP 列表预览和 1000px JPEG 大图；列表懒加载，选集大图进入视线时加载，详情弹层大图在点击时加载、关闭时移除图片地址，避免预先请求整批大图。

## 摄影

- 保留原照片墙和时间线排版，统一 4:3 缩略图，默认按拍摄日倒序；搜索图片描述、札记和日期。
- 时间线只显示日期和照片，不把 alt 显示为图下注释；札记保持大图里的斜体衬线和引号样式，无札记时使用轻淡占位。
- 大图和札记整体在全屏遮罩上水平、垂直居中，图片适度缩小并保持完整比例；背景半透明并高斯模糊，无边框和关闭按钮。保留两侧切换、方向键、Escape、点击背景关闭和焦点返回，错误状态不残留前一张。
- 本地批次目录只有本次上传照片；处理所有输入，无历史自动跳过。
- RAW 提取内嵌 JPEG，不显影；JPEG 直接生成大图与预览，原件保留本地。
- 上传成功并验证后，AI 自动完成 JSON 记录、构建和已授权的发布。

## 文档与内容维护

保留 Markdown、Shiki 双主题、目录 rail、Pagefind 和双语 UI；正文不机器翻译。开发模式不加载全文搜索索引，构建后预览。

取消独立媒体 CLI，通过 `maintenance/media/` 文档与小工具让 AI 执行录入、处理、上传、校验、数据更新。上传对象与发布网页是两个步骤。R2 已清空，公开数组从空开始；未重新上传的旧媒体不得引用。

## 验收

- 普通直接访问、链接跳转、前进/后退均可用；内页转场轻柔，首页动效不冲突。
- zh/en、主题、移动抽屉、设置和文档搜索工作正常。
- 专辑不存在播放控件；空清单显示空态，新数据可搜索，详情弹层可打开和关闭。
- 摄影沿用 4:3 缩略图网格，大图完整展示；键盘操作和错误处理正常。
- 文档明确说明 RAW 提取、R2 上传、对象验证、JSON 和部署步骤。
- 类型检查、静态构建、数据检查和 diff 检查通过。
